# Project Statement

## Project Title
Personal Financial Tracker

## Problem Statement
Users often need a simple way to record income and expenses and determine their available balance. Manual calculation can lead to mistakes and makes it harder to review spending. The project addresses this problem with a menu-driven Python application that accepts income and expense information and produces basic financial summaries.

## Scope
The project covers basic personal financial tracking through a command-line interface. It supports income entry, expense entry, expense viewing, and balance calculation. The prototype stores information during program execution.

## Target Users
- Students
- Individuals managing personal allowances or salary
- Beginners learning Python programming

## High-Level Features
1. Income Management
2. Expense Management
3. Expense Listing
4. Balance Calculation
5. Menu-Based User Interaction

## Inputs
- Salary
- Extra income
- Expense category
- Expense amount
- Menu choice

## Outputs
- Confirmation messages
- Expense list
- Total income
- Total expenses
- Remaining balance
